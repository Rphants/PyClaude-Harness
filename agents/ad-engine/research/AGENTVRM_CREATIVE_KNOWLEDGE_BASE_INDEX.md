## KEY METRICS TO TRACK (From QUICK_REFERENCE.md)

### MUST MONITOR (Kill Ads If Poor)
```
3-Second Hook Rate < 15% → PAUSE immediately
Click-Through Rate < 0.5% → Not resonating, pause
Cost Per Click > $2.50 → Audience or messaging issue
```

### SHOULD MONITOR (Optimize If Improving)
```
Engagement Rate: Likes, comments, shares (emotional impact)
Relevance Score: Aim for 8+ (Meta's quality score)
Ad Frequency: If >3, fatigue setting in, refresh creative
```

### CONVERSION METRICS (Measure Campaign Success)
```
Conversion Rate: Target 10-15% (vs. 8.95% baseline)
```
